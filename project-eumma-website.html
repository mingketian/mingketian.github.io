1Problem

A student organization changes its board every year, so its website has to outlast its authors. The site must cover events, competitions and training, the team, and how to join, and any future board must be able to edit it without installing a framework, running a build, or maintaining a server.

2Design

Table 1. Design decisions.
ComponentImplementation
Single pageThe whole site is one HTML file with no framework, build pipeline, or server; GitHub Pages serves it unchanged.
Events as dataEach event is one entry in an events list; the month calendar, term archive, category filters, and poster gallery are generated from it.
Publishing toolsPython scripts build the public copy (removing drafts and internal notes, checking that the HTML stays balanced), generate QR codes in the site palette, and update the recruitment poster.
Live mastheadCanvas draws level sets of a non-convex objective with momentum gradient-descent trajectories; it pauses for reduced-motion settings or when off-screen.
