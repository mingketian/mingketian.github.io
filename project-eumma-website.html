OVERVIEW

The official EUMMA website: a home for events, competitions and training, the team, and how to join. It is built to outlast its authors, as one self-contained page that any future board can edit without installing anything.

How it works

  1. 01

    One self-contained page

    The whole site is a single HTML file with no framework, build pipeline, or server, so future boards can keep it running; GitHub Pages serves it unchanged.

  2. 02

    Events as data

    Every event is one entry in an events list; the month calendar, term archive, category filters, and poster gallery are all generated from it.

  3. 03

    Publishing tools

    Python scripts build the public copy (removing drafts and internal notes and checking that the HTML stays balanced), generate QR codes in the site's palette, and update the recruitment poster.

  4. 04

    Live masthead

    The header draws level sets of a non-convex objective with momentum gradient-descent trajectories running on it, and pauses for reduced-motion settings or when off-screen.
