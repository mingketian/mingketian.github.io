1Problem and significance

A GPS trajectory is a sequence of \(N\) timestamped locations. Staypoint detection labels every point as stop or move:

\[\begin{gathered}\mathcal{T}=\{(\ell_i,t_i)\}_{i=1}^{N},\qquad \ell_i=(\mathrm{lat}_i,\mathrm{lon}_i),\\ y_i\in\{\text{stop},\text{move}\}.\end{gathered}\]

Here \(\ell_i\) are coordinates and \(t_i\) timestamps. A maximal contiguous span labeled stop defines a dwell episode \(s\). The target therefore has two parts: point-level movement evidence and the temporal coherence of the resulting span.

  • Staypoints are the unit that mobility analysis consumes. Home/work inference, next-location prediction, anomaly detection, activity recognition, and duration forecasting all operate on staypoint-level histories, their semantic labels, and their dwell times.
  • Detection requires motion and place jointly. Low speed may indicate an activity, congestion, a traffic signal, or positioning noise. Separating these cases requires spatial concentration, temporal persistence, arrival and departure transitions, and whether the surrounding geography supports a stay.
  • Cities differ. Sampling rates, mobility patterns, and available geographic context change across regions, so a representation learned in one city must transfer and must remain usable when some context source is missing.

The goal is to use staypoint detection as a pretext task: learn an encoder on a labeled source city that produces a fused state \(\mathbf{h}_i\) per point, a coherent stop/move decoding, and a staypoint representation \(\mathbf{z}_s\),

\[\mathcal{T}\ \longrightarrow\ (\mathbf{m}_i,\mathbf{g}_i)\ \longrightarrow\ \mathbf{h}_i\ \longrightarrow\ \mathrm{CRF}\ \longrightarrow\ \mathbf{z}_s,\]

such that the frozen \(\mathbf{z}_s\), read by lightweight task-specific heads, supports diverse downstream tasks in the source city and in other cities.

2Research questions

Equation (2) makes three claims that must be tested separately: the pretext must be learnable as coherent spans; the pooled representation must be reusable without per-task backbone training; and it must survive a change of city, with or without unlabeled target data. A fourth question asks which geographic sources the transfer depends on.

3Method

StayBERT has five components: a motion view producing \(\mathbf{m}_i\in\mathbb{R}^{256}\); a place view producing a query-conditioned geographic state \(\mathbf{g}_i\in\mathbb{R}^{128}\); a dimension-wise gate that fuses them into \(\mathbf{h}_i\in\mathbb{R}^{128}\); a linear-chain CRF with marginal-weighted staypoint pooling; and a dwell-structured pretraining objective. Geo-Conditional Test-Time Self-Training (Geo-TTST) is an optional target-city adaptation step that updates only the CRF head. Algorithm 1 gives pretraining and downstream use; Algorithm 2 gives Geo-TTST.

3.1Motion view

The motion view encodes how the user is moving. A temporal convolutional front-end (four blocks) produces a smoothed coordinate estimate from the input trace. For point \(i\), the motion token combines this estimate with the original coordinates, the elapsed time \(\Delta t_i\), and the log-speed. A two-layer Transformer (\(d_{\mathrm{model}}=256\), eight heads) contextualizes the tokens and outputs \(\mathbf{m}_i\in\mathbb{R}^{256}\). The stream is trained jointly with the pretext and captures velocity changes, temporal persistence, and approach and departure patterns around dwell boundaries.

3.2Place view and query-conditioned composition

The place view builds a point representation from four sources of geographic evidence, assembled offline on a common grid and queried at each point.

  • Geodesic anchor. Sphere2Vec maps longitude and latitude to spherical basis functions at 16 geometrically spaced frequencies; the 48-dimensional basis is projected to a 64-dimensional query \(\mathbf{q}_i=\Phi_{\mathrm{loc}}(\ell_i)\).
  • Functional neighborhood. A KD-tree retrieves up to \(K=20\) POIs within 0.005° of the grid center, in six categories (residential, workplace, restaurant, recreation, education, religion). Each POI token adds a learned type embedding to a multi-scale encoding of its displacement from \(\ell_i\); four-head attention from \(\mathbf{q}_i\) summarizes the set into \(\mathbf{c}^{\mathrm{poi}}_i\in\mathbb{R}^{64}\).
  • Mobility structure. On a 0.005° grid, a spatial graph (eight-neighbor adjacency plus five-nearest-neighbor links in grid-feature space) and a directed flow graph (consecutive transitions observed at least ten times, weights \(\log(1+\text{count})\)) are encoded by separate two-layer GraphSAGE branches, concatenated, and projected to \(\mathbf{c}^{\mathrm{net}}_i\in\mathbb{R}^{64}\). Both graphs are built per city; this is the only city-specific source.
  • Regional semantics. A text description of each cell (coordinates, nearby POI counts, dominant land use) is embedded by a frozen Sentence-BERT encoder (all-MiniLM-L6-v2) and reduced to 64 dimensions by PCA, giving \(\mathbf{c}^{\mathrm{sem}}_i\).

The available tokens form a context bank, and the Sphere2Vec query attends over it:

\[C_i=\big[\mathbf{c}^{\mathrm{poi}}_i;\ \mathbf{c}^{\mathrm{net}}_i;\ \mathbf{c}^{\mathrm{sem}}_i\big],\]
\[\mathbf{g}_i=W_o\,\mathrm{LN}\big(\mathbf{q}_i+\mathrm{MHA}(\mathbf{q}_i,C_i,C_i)\big)\in\mathbb{R}^{128},\]

where \(\mathrm{MHA}\) is four-head attention with query \(\mathbf{q}_i\), \(\mathrm{LN}\) is layer normalization, and \(W_o\) projects to the 128-dimensional place state. A missing source is removed from \(C_i\) rather than replaced by a placeholder; with no external source, \(\mathbf{g}_i\) reduces to the projected Sphere2Vec query. Three of the four sources (Sphere2Vec, POIs, regional semantics) have a common cross-city interface, which is what permits direct transfer (§3.6).

3.3Motion–place gate

The two states differ in dimension and statistics. They are projected into a shared 128-dimensional space and combined by a point-wise, dimension-wise gate:

\[\begin{gathered}\tilde{\mathbf{m}}_i=W_m\mathbf{m}_i,\qquad \tilde{\mathbf{g}}_i=W_g\mathbf{g}_i,\\ \boldsymbol{\alpha}_i=\sigma\big(W_\alpha[\mathbf{m}_i;\mathbf{g}_i]\big),\end{gathered}\]
\[\mathbf{h}_i=\boldsymbol{\alpha}_i\odot\tilde{\mathbf{m}}_i+(1-\boldsymbol{\alpha}_i)\odot\tilde{\mathbf{g}}_i,\]

with \(\mathbf{h}_i,\boldsymbol{\alpha}_i\in\mathbb{R}^{128}\), \(\sigma\) the logistic function, and \(\odot\) the element-wise product. Because \(\boldsymbol{\alpha}_i\) is a vector, some dimensions can follow sharp motion changes while others retain stable functional context. The mean of \(1-\boldsymbol{\alpha}_i\) is reused in §3.6 as a measure of reliance on the place stream.

3.4CRF decoding and staypoint pooling (RQ1, RQ2)

A linear-chain CRF scores a label sequence \(\mathbf{y}\) for trajectory \(\mathcal{T}\) with fused states \(\{\mathbf{h}_i\}_{i=1}^N\):

\[S_\theta(\mathcal{T},\mathbf{y})=\sum_{i=1}^{N}e_\theta(\mathbf{h}_i)_{y_i}+\sum_{i=2}^{N}A_{y_{i-1},y_i},\]

where \(e_\theta(\mathbf{h}_i)\) is the stop/move emission vector and \(A\) the learned transition matrix. The conditional likelihood and per-trajectory negative log-likelihood are

\[\begin{gathered}P_\theta(\mathbf{y}\mid\mathcal{T})=\frac{\exp S_\theta(\mathcal{T},\mathbf{y})}{\sum_{\mathbf{y}'}\exp S_\theta(\mathcal{T},\mathbf{y}')},\\ \mathcal{L}^{(k)}_{\mathrm{CRF}}=-\log P_\theta\big(\mathbf{y}^{(k)}\mid\mathcal{T}^{(k)}\big).\end{gathered}\]

Viterbi decoding turns local evidence into coherent dwell intervals. For an interval \(s\), let \(p_i\) be the CRF marginal probability of stop at point \(i\). The staypoint representation is the marginal-weighted mean of the point states:

\[w_i=\frac{p_i}{\sum_{j\in s}p_j},\qquad \mathbf{z}_s=\sum_{i\in s}w_i\,\mathbf{h}_i\in\mathbb{R}^{128}.\]

The interval \(s\) is either supplied during representation evaluation or taken from a CRF-decoded stop span. \(\mathbf{z}_s\) is the representation consumed by all downstream heads.

3.5Dwell-structured pretraining objective (RQ1)

Sequence level. Long stop interiors would dominate an unweighted CRF loss. The primary term normalizes by valid length and up-weights trajectories that contain move points:

\[\mathcal{L}_{\mathrm{bal\text{-}CRF}}=\frac{1}{|\mathcal{D}|}\sum_{k}\omega_k\,\frac{\mathcal{L}^{(k)}_{\mathrm{CRF}}}{N_k},\]
\[\begin{gathered}\omega_k=1+(w_{\mathrm{move}}-1)\,r_k,\\ r_k=\frac{1}{N_k}\sum_{i}\mathbf{1}\big[y^{(k)}_i=\text{move}\big],\end{gathered}\]

where \(N_k\) is the valid length of trajectory \(k\), \(r_k\) its move-point fraction, and \(w_{\mathrm{move}}=20\).

Observation level. Adaptive trajectory resampling (ATR) keeps an order-preserving random fraction \(\rho\) of observations and recomputes elapsed-time features:

\[\widetilde{\mathcal{T}}=\mathcal{A}_{\mathrm{ATR}}(\mathcal{T};\rho),\qquad \rho\in[\rho_{\min},1].\]

ATR is an augmentation, not a loss: the same ten-minute dwell may be seen every 10 or every 30 seconds, which discourages dependence on one sampling rate. All terms of the full objective are evaluated on \(\widetilde{\mathcal{T}}\):

\[\begin{aligned}\mathcal{L}_{\mathrm{dwell}}=\mathcal{L}_{\mathrm{bal\text{-}CRF}}&+\lambda_{\mathrm{rec}}\mathcal{L}_{\mathrm{rec}}\\&+\lambda_{\mathrm{bnd}}\mathcal{L}_{\mathrm{bnd}}+\lambda_{\mathrm{seg}}\mathcal{L}_{\mathrm{seg}}.\end{aligned}\]

Point level. For the set \(\mathcal{M}\) of masked valid positions, a decoder \(d_\psi\) reconstructs the normalized coordinates \(\bar{\ell}_i\):

\[\mathcal{L}_{\mathrm{rec}}=\frac{1}{|\mathcal{M}|}\sum_{i\in\mathcal{M}}\big\lVert d_\psi(\mathbf{h}_i)-\bar{\ell}_i\big\rVert_2^2.\]

Transition level. For the sparse set \(\mathcal{B}=\{i:y_i\neq y_{i-1}\}\) of labeled arrival and departure points,

\[\mathcal{L}_{\mathrm{bnd}}=-\frac{1}{|\mathcal{B}|}\sum_{i\in\mathcal{B}}\log P_\theta(y_i\mid\mathcal{T})_i.\]

Segment level. For each ground-truth dwell span \(s\in\mathcal{S}\), let \(p_i=P_\theta(y_i=\text{stop}\mid\mathcal{T})\) and let \(\widehat{\ell}_i\) be the predicted coordinate. The probability-weighted and geometric centroids are

\[\mu^{p}_s=\frac{\sum_{i\in s}p_i\,\widehat{\ell}_i}{\sum_{i\in s}p_i},\qquad \mu_s=\frac{1}{|s|}\sum_{i\in s}\widehat{\ell}_i,\]

and the segment term aligns them while penalizing the mean stop probability \(\bar{p}_{\partial s}\) in the region just outside the span:

\[\mathcal{L}_{\mathrm{seg}}=\frac{1}{|\mathcal{S}|}\sum_{s\in\mathcal{S}}\Big[\big\lVert\mu^{p}_s-\mu_s\big\rVert_1+\beta\,\bar{p}_{\partial s}\Big].\]

The four terms model sequence coherence, point-level geometry, motion transitions, and complete dwell structure, respectively.

GeoContext warmup. To keep uncalibrated place features from dominating early training, the place state is scaled at epoch \(e\) by

\[\alpha_e=\min\!\Big(0.01+0.99\,\frac{e}{20},\ 1\Big).\]

This is an optimization schedule, not part of the representation.

3.6Cross-city adaptation: Geo-TTST (RQ3)

Direct transfer. The source-pretrained model is applied to a target city with no target labels. The mobility-graph token is omitted when no compatible target graph exists, and any other missing source is removed from \(C_i\) in Eq. (3).

Geo-conditioned confidence. When unlabeled target windows \(\mathcal{D}_t=\{\mathcal{T}_j\}\) are available, Geo-TTST self-trains on confident pseudo-labels. Predictive confidence alone can be unreliable under geographic shift, so it is combined with the place-reliance signal from the gate. In round \(r\), with CRF marginal \(p^{(r)}_{j,i}(y)\) and gate \(\boldsymbol{\alpha}^{(r)}_{j,i}\),

\[\begin{gathered}\hat{y}^{(r)}_{j,i}=\arg\max_{y}\,p^{(r)}_{j,i}(y),\\ a^{\mathrm{geo},(r)}_{j,i}=\operatorname{mean}_d\big(1-\alpha^{(r)}_{j,i,d}\big),\end{gathered}\]
\[c^{(r)}_{j,i}=\gamma\,\max_{y}\,p^{(r)}_{j,i}(y)+(1-\gamma)\,a^{\mathrm{geo},(r)}_{j,i},\]

where \(\gamma\in[0,1]\) balances predictive certainty against geographic support. With \(v_{j,i}\in\{0,1\}\) marking valid, non-padded points, the selected set is

\[\mathcal{I}^{(r)}=\big\{(j,i):\ c^{(r)}_{j,i}>\tau,\ v_{j,i}=1\big\}.\]

Restricted update. The motion encoder, GeoContext encoder, and fusion module are frozen; only the CRF parameters \(\theta_{\mathrm{CRF}}\) are updated. Because confidence filtering can keep non-contiguous points, the loss uses the differentiable CRF marginals at the selected points instead of a full-sequence likelihood:

\[\mathcal{L}^{(r)}_{\mathrm{TTST}}=-\frac{1}{|\mathcal{I}^{(r)}|}\sum_{(j,i)\in\mathcal{I}^{(r)}}\log p_{\theta_{\mathrm{CRF}}}\big(\hat{y}^{(r)}_{j,i}\mid\mathcal{T}_j\big)_i.\]

Updating only the CRF head recalibrates stop/move decoding without overwriting \(\mathbf{h}_i\). Target stop/move labels are never passed to the model and are used only for offline evaluation.

Algorithm 2  CRF-only Geo-Conditional Test-Time Self-Training

Input: source-pretrained \(\theta=(\theta_{\mathrm{enc}},\theta_{\mathrm{fuse}},\theta_{\mathrm{CRF}})\); unlabeled target windows \(\mathcal{D}_t\); rounds \(T\), update epochs \(K\), threshold \(\tau\), weight \(\gamma\), learning rate \(\eta\).  Output: adapted \(\theta_{\mathrm{CRF}}\).

  1. Omit geographic sources unavailable in the target domain; freeze \(\theta_{\mathrm{enc}}\) and \(\theta_{\mathrm{fuse}}\)
  2. for \(r=1,\dots,T\):
  3. evaluation mode: for each target mini-batch, compute marginals \(p^{(r)}\), gates \(\boldsymbol{\alpha}^{(r)}\), and valid mask \(v\)  ▷ Eq. (8)
  4.  set \(\hat{y}^{(r)}_{j,i}\) and \(c^{(r)}_{j,i}\);  \(\hat{m}^{(r)}_{j,i}\leftarrow\mathbf{1}[c^{(r)}_{j,i}>\tau]\,v_{j,i}\)  ▷ Eqs. (19)–(21)
  5. training mode: for \(k=1,\dots,K\), for each shuffled target mini-batch:
  6.  recompute CRF marginals with the current \(\theta_{\mathrm{CRF}}\); skip the batch if it has no selected points
  7.  compute \(\mathcal{L}^{(r)}_{\mathrm{TTST}}\); update only \(\theta_{\mathrm{CRF}}\) with AdamW  ▷ Eq. (22); pseudo-labels fixed within the round
  8. return \(\theta_{\mathrm{CRF}}\)

The reported Atlanta configuration uses \(T=3\) rounds, \(K=1\) update epoch per round, \(\tau=0.95\), \(\gamma=0.5\), learning rate \(5\times10^{-5}\), batch size 32, AdamW weight decay \(10^{-4}\), and gradient-norm clipping at 1.0, with the city-specific road graph disabled.
