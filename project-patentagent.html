Patent Prior-Art Agent: From Retrieval to Evidence-Grounded Analysis

LangGraph · FAISS · PatentSBERTa · BM25 · Learned reranking · RAG

Ranking metrics and human rating
On this pageProblemMethodResults

1Problem

Given a patent claim, an invention idea, or a vague search query, the agent returns a ranked prior-art set, a limitation-level evidence chart, and an answer in which every statement traces back to retrieved patent text. Plain retrieval-augmented generation ranks by a single similarity and writes from whatever it retrieves, so it can neither rank by claim limitations nor show which passage supports which statement.

2Method

Table 1. Agent stages (orchestrated with LangGraph).
StageOperation
1 PlanClassify the turn (new search, follow-up, comparison, filter) and decompose the claim into limitations \(\ell_1,\dots,\ell_m\).
2 RecallCoarse recall from a persistent FAISS index of 17,877 patents with 768-dimensional PatentSBERTa vectors.
3 RerankLearned linear reranker over dense, BM25, and field-lexical scores (Eq. 1), trained on PAR4PC.
4 AlignFor each limitation, select the strongest title, abstract, or claim snippet (Eq. 2) and build the claim chart.
5 SynthesizeWrite the answer from the extracted evidence only.
6 VerifyLabel the answer supported, partially supported, or unsupported against the evidence, with a reason.

For a query \(q\) and candidate patent \(d\), the reranker combines the three retrieval signals linearly:

\[s(q,d)=\mathbf{w}^{\top}\big[\,s_{\mathrm{dense}}(q,d),\ s_{\mathrm{BM25}}(q,d),\ s_{\mathrm{field}}(q,d)\,\big],\]

with \(\mathbf{w}\) fit on PAR4PC. Evidence is then chosen per limitation over the fields \(f\in\{\text{title},\text{abstract},\text{claims}\}\) of each retained patent:

\[e(\ell_i,d)=\arg\max_{\text{snippet }x\,\in\,f(d)}\ \mathrm{sim}(\ell_i,x),\]

so every row of the claim chart, and every sentence of the answer, carries a pointer to a specific passage.
