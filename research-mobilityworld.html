1Problem and significance

Let \(\mathcal{U}\) be a set of human agents. The data are trajectory episodes of time-stamped positioning observations, situated in an external geographic world:

\[\mathcal{D}=\{\mathcal{T}_n\}_{n=1}^{N},\qquad \mathcal{T}_n=\big(u_n,\{o_{n,t}\}_{t=1}^{T_n}\big),\qquad o_{n,t}=(x_{n,t},\tau_{n,t}),\qquad W=(G,\mathcal{P}),\ \ G=(V,E).\]

Here \(u_n\in\mathcal{U}\) identifies the agent, \(x_{n,t}\in\mathbb{R}^2\) is a measured location projected into a local metric frame, and \(\tau_{n,t}\) is its timestamp; elapsed intervals vary with acquisition cadence and missing records. \(G\) is a directed, spatially embedded road network whose edges carry polyline geometry and attributes (length, class, directionality, speed, availability), and \(\mathcal{P}\) is a set of categorized points of interest (POIs). For a length-\(T\) episode \(\mathbf{o}=(o_1,\dots,o_T)\), the underlying mobility process is a state–action path

\[\mathbf{z}=(\mathbf{s},\mathbf{a}),\qquad \mathbf{s}=(s_1,\dots,s_T),\quad \mathbf{a}=(a_1,\dots,a_{T-1}),\qquad s_{t+1}\sim p_\theta(s_{t+1}\mid s_t,a_t),\]

where \(s_t\in\mathbb{R}^{d_s}\) is a predictive latent state, sufficient to explain the current observation and predict subsequent evolution, and \(a_t\in\mathbb{R}^{d_a}\) is an interval-level latent action that carries the process from \(s_t\) to \(s_{t+1}\). Profile, query context, and geography may change which action is supported, but cannot bypass \(a_t\) to set the next state. A task is posed as a query

\[\mathcal{Q}=(\nu_q,\mathcal{E}_q),\qquad \mathcal{E}_q=\big(\mathcal{I}_q,\mathcal{O}_q,\mathbf{o}_{\mathcal{O}_q},\mathcal{B}_q,\varpi_q,W_q\big),\qquad \nu_q\in\{\textsf{Infer},\textsf{Roll},\textsf{Plan}\},\]

with query grid \(\mathcal{I}_q\), exposed indices \(\mathcal{O}_q\) and their observations, boundary conditions \(\mathcal{B}_q\), optional behavioral or task conditions \(\varpi_q\), and evaluation world \(W_q\). With valid transitions \(\mathcal{K}_q=\{t: t,t+1\in\mathcal{I}_q\}\), the candidate latent process and the model output are

\[\mathbf{z}_q=\big(\mathbf{s}_{\mathcal{I}_q},\mathbf{a}_{\mathcal{K}_q}\big)\in\Omega_q^{\mathrm{MAP}},\qquad \widehat{\mathbf{z}}_q:=\mathrm{MAP}_\Theta(\mathcal{E}_q)\in\Omega_q^{\mathrm{MAP}},\]

where \(\Omega_q^{\mathrm{MAP}}\) holds the continuous boundary constraints, \(\Omega_q^{\mathrm{exec}}\) the graph-connected continuations satisfying hard execution constraints, and \(\Theta\) all learnable parameters.

  • Observations are poor and actions are absent. Traces are sparse, noisy positions; the decision behind each move is never recorded, and one displacement admits several explanations. Control world models assume observed actions; visual world models assume dense observations.
  • Transitions must be executable. Movement is constrained by the road network and shaped by POI semantics, so a continuation is useful only if it is a legal path in \(W_q\). Latent-action models do not enforce this.
  • Tasks share one process but are modeled separately. Prediction, generation, completion, re-identification, and staypoint detection are usually separate input–output models, although all observe the same decision-driven process.

The goal is one parameter set \(\Theta\) per dataset that answers every query through three operators on the same reconciled path, with no task-specific heads or fine-tuning:

\[\mathcal{M}_\Theta(\mathcal{Q})=\begin{cases}\mathrm{Readout}_q(\widehat{\mathbf{z}}_q), & \nu_q=\textsf{Infer},\\ \mathrm{Roll}^{H_q}_\Theta(\varsigma_q;W_q,\varpi_q), & \nu_q=\textsf{Roll},\\ \mathrm{Exec}_{W_q}(\mathbf{c}^\star_q), & \nu_q=\textsf{Plan},\end{cases}\qquad \mathbf{c}^\star_q:=\arg\max_{\mathbf{c}\in\Omega^{\mathrm{exec}}_q}\big\{\mathcal{S}^{\mathrm{exec}}_{\Theta,q}(\mathbf{c}\mid\varsigma_q)-C_q(\mathbf{c})\big\},\]

where \(\varsigma_q\) is the reconciled state, preceding action, fixed profile, and query context from which a continuation begins, \(H_q\) the rollout horizon, \(\mathcal{S}^{\mathrm{exec}}\) the learned local executable score, and \(C_q\) an explicit query cost.

Each operator gives a research question; a fourth asks which components are responsible.

3Method

MobilityWorld has two levels. Locally, a state encoder, a profile memory, a behavioral actor, an action-conditioned transition, and a world-support factor define one transition (§3.1–3.3); Structured Consistency Learning trains them through Predictive State Consistency and Latent Action Consistency (§3.4–3.5). Globally, a differentiable temporal MAP step composes the local factors over the whole query interval (§3.6), and training differentiates through it (§3.7). Algorithm 1 gives the pipeline.

Algorithm 1  MobilityWorld training and query answering

Input: training queries \(\mathcal{D}_{\mathrm{train}}\); world \(W\); test query \(\mathcal{Q}=(\nu_q,\mathcal{E}_q)\).  Output: shared \(\Theta\); answer \(\mathcal{M}_\Theta(\mathcal{Q})\).

  1. Training. for each training query \(q\sim\mathcal{D}_{\mathrm{train}}\):
  2. encode visible states \(s^\phi_t\sim q_\phi(s_t\mid o_t)\); initialize hidden states from permitted boundaries or model propagation; \(a^{(0)}_t\leftarrow 0\)  ▷ Eq. (7)
  3. \(\widehat{\mathbf{z}}^{(K_{\mathrm{MAP}})}_{\Theta,q}\leftarrow\mathrm{Solve}^{K_{\mathrm{MAP}}}_\Theta(\mathbf{z}^{(0)}_q)\): projected-gradient steps on \(\mathcal{J}_{\mathrm{MAP}}\), restoring boundary states after each step  ▷ Eqs. (18)–(20)
  4. evaluate \(\mathcal{L}_{\mathrm{obs},t}\), \(\mathcal{E}_{\mathrm{tr},t}\), \(\mathcal{L}^{(H)}_{\mathrm{roll},t}\), \(\mathcal{E}_{\mathrm{beh},t}\), \(\mathcal{E}_{\mathrm{world},t}\) on the reconciled path  ▷ Eqs. (11)–(16)
  5. update \(\Theta\) by the gradient of \(\mathcal{L}_{\mathrm{SCL}}\) through the solver  ▷ Eqs. (17), (21); implemented objective Eq. (27)
  6. Query answering (\(\Theta\) fixed): \(\widehat{\mathbf{z}}_q\leftarrow\mathrm{MAP}_\Theta(\mathcal{E}_q)\) with \(K_{\mathrm{MAP}}\) backtracked steps on the exposed evidence  ▷ Eq. (19)
  7. if \(\nu_q=\textsf{Infer}\): return \(\mathrm{Readout}_q(\widehat{\mathbf{z}}_q)\)
  8. if \(\nu_q=\textsf{Roll}\): from \(\varsigma_q\), repeat \(H_q\) times: enumerate legal continuations, rank them with actor, transition, and world factors, execute the best on \(G\), align its endpoint  ▷ Eq. (10)
  9. if \(\nu_q=\textsf{Plan}\): beam search (width 64) over legal continuation sequences scored by \(\mathcal{S}^{\mathrm{exec}}-C_q\); return the best route that satisfies every hard constraint, else report failure  ▷ Eq. (5)

3.1Local transition and predictive state

The architectural primitive is one transition over \((o_t,s_t,a_t,s_{t+1},W_q)\), with five factors:

\[\begin{aligned}&\text{State encoder:} && s_t\sim q_\phi(s_t\mid o_t),\\ &\text{Profile:} && \alpha_q=M_\rho\big(\{s^\phi_{t'}: t'\in\mathcal{I}^{\mathrm{hist}}_q\}\big),\\ &\text{Actor:} && a_t\sim\pi_\psi(a_t\mid h_t),\\ &\text{Transition:} && s_{t+1}\sim p_\theta(s_{t+1}\mid s_t,a_t),\\ &\text{World support:} && \kappa_\omega(s_t,a_t;g_t)\in(0,1].\end{aligned}\]

Here \(h_t=(s_t,a_{t-1},\alpha_q,\varpi_q)\) is the actor context, \(\alpha_q\) a profile summarizing the permitted history \(\mathcal{I}^{\mathrm{hist}}_q\), and \(g_t=\Gamma_{W_q}(\ell_\chi(s_t))\) the local spatial feature. The encoder maps each observation to a diagonal-Gaussian belief from Fourier coordinate features and cyclic local-time features in a gated residual MLP:

\[q_\phi(s_t\mid o_t)=\mathcal{N}\big(s_t;\,\mu_\phi(x_t,\tau_t),\,\mathrm{diag}\big(\sigma^2_\phi(x_t,\tau_t)\big)\big).\]

This belief initializes, but does not fix, the optimizable state. A metric decoder \(\ell_\chi\) maps the state back to coordinates, and an exponential-moving-average (EMA) copy of the encoder supplies stop-gradient targets \(\bar{s}_t\). In the reported checkpoint \(d_s=32\) and \(d_a=16\); coordinates are normalized by 10,000 m and encoded with 16 log-spaced Fourier bands.

3.2Dynamics and behavioral actor

The transition is a Gaussian mixture whose parameters are produced from \((s_t,a_t)\):

\[p_\theta(s_{t+1}\mid s_t,a_t)=\sum_{k=1}^{K_s}w_{t,k}\,\mathcal{N}\big(s_{t+1};\,\mu_{t,k},\,\mathrm{diag}\big(\sigma^{2,s}_{t,k}\big)\big).\]

During inference it couples adjacent states through the free action; during rollout it is applied recursively. Each \(a_t\) is a free latent variable optimized jointly with the states. The actor is a multimodal prior over interval-level controls, parameterized as a residual around the previous action:

\[\pi_\psi(a_t\mid h_t)=\sum_{j=1}^{K_a}\varrho_{t,j}\,\mathcal{N}\big(a_t;\,a_{t-1}+\delta_{t,j},\,\mathrm{diag}\big(\sigma^{2,a}_{t,j}\big)\big).\]

The residual form captures short-term persistence; \(\alpha_q\) carries longer-term regularity. Both mixtures use \(K_s=K_a=3\) components. Profile, geography, and query conditions affect the next state only by changing which action is selected.

3.3Semantic–geographic world interface

The world enters through two interfaces. The differentiable one evaluates, at the decoded location \(y_t=\ell_\chi(s_t)\), a spatial field \(g_t=\Gamma_{W_q}(y_t)\) of local road attributes and POI semantics; \(\kappa_\omega(s_t,a_t;g_t)\) scores whether an action is supported there. It guides inference but does not guarantee legality. The executable one is \(\mathfrak{E}^{\triangle}_{W_q}=(\mathcal{C}^{\triangle}_{W_q},\zeta_{W_q},\mathrm{Exec}_{W_q},\mathrm{Align}_\chi)\): \(\mathcal{C}^{\triangle}_{W_q}(y_t)\) enumerates graph-legal continuations realizable within one interval (at most 12 outgoing edges), \(\zeta_{W_q}\) maps each into the shared action space, \(\mathrm{Exec}_{W_q}\) returns its exact road geometry and endpoint, and \(\mathrm{Align}_\chi\) reconciles that endpoint with the predicted next state. During rollout and planning the legal candidates are ranked by

\[c^\star_t=\arg\max_{c\in\mathcal{C}^{\triangle}_{W_q}(y_t)}\ \mathcal{S}^{\mathrm{exec}}_\Theta\big(c\mid s_t,a_{t-1},\alpha_q,\varpi_q,W_q\big),\]

where \(\mathcal{S}^{\mathrm{exec}}_\Theta\) combines the actor, transition, and world factors. The selected continuation is executed exactly on \(G\). The road graph therefore determines feasibility, and the learned model determines which feasible continuation is preferred.

3.4Predictive State Consistency

A state that explains one noisy measurement need not predict the next one, and a state that supports one-step prediction may drift under recursion. The state is constrained at three scales. Observation consistency grounds it in coordinates:

\[\mathcal{L}_{\mathrm{obs},t}:=\mathbb{E}_{s_t\sim q_\phi(\cdot\mid o_t)}\big[\lVert\ell_\chi(s_t)-x_t\rVert_2^2\big].\]

Transition consistency requires the action-conditioned prediction from the online state \(s^\phi_t\) to match the stop-gradient EMA target \(\bar{s}_{t+1}\):

\[\mathcal{E}_{\mathrm{tr},t}(a):=-\log p_\theta\big(\bar{s}_{t+1}\mid s^\phi_t,a\big).\]

Closed-loop rollout consistency starts from \(\widehat{s}_t:=s^\phi_t\) and runs \(H\) steps in which the spatial context is re-queried and the action re-selected at every predicted state:

\[\begin{aligned}\widehat{g}_{t+h}&:=\Gamma_{W_q}\big(\ell_\chi(\widehat{s}_{t+h})\big),\\ \widehat{a}_{t+h}&:=\arg\max_{a\in\mathbb{R}^{d_a}}\Big\{\log\pi_\psi\big(a\mid\widehat{h}_{t+h}\big)+\log\kappa_\omega\big(\widehat{s}_{t+h},a;\widehat{g}_{t+h}\big)\Big\},\\ \widehat{s}_{t+h+1}&:=\mathbb{E}_{s'\sim p_\theta(\cdot\mid\widehat{s}_{t+h},\widehat{a}_{t+h})}[s'],\end{aligned}\]

with \(\widehat{h}_{t+h}=(\widehat{s}_{t+h},\widehat{a}_{t+h-1},\alpha_q,\varpi_q)\). The rollout loss compares predicted and target states in both representation and readout:

\[\mathcal{L}^{(H)}_{\mathrm{roll},t}:=\sum_{h=1}^{H}d_{\mathrm{state}}\big(\widehat{s}_{t+h},\bar{s}_{t+h}\big),\qquad d_{\mathrm{state}}(s,s'):=\lVert s-s'\rVert_2^2+\lambda_y\lVert\ell_\chi(s)-\ell_\chi(s')\rVert_2^2.\]

3.5Latent Action Consistency and the joint objective

A displacement alone admits several actions. The action is identified operationally by three energies: it must explain the state change (\(\mathcal{E}_{\mathrm{tr},t}\), Eq. 12), remain probable under the causal actor prior, and be supported by the local road–POI world:

\[\mathcal{E}_{\mathrm{beh},t}(a):=-\log\pi_\psi(a\mid h_t),\]
\[\mathcal{E}_{\mathrm{world},t}(a):=-\log\kappa_\omega\Big(s^\phi_t,a;\,\Gamma_{W_q}\big(\ell_\chi(s^\phi_t)\big)\Big).\]

Structured Consistency Learning combines both axes:

\[\begin{aligned}\mathcal{L}_{\mathrm{SCL}}:=\ &\lambda_{\mathrm{obs}}\textstyle\sum_t\mathcal{L}_{\mathrm{obs},t}+\lambda_{\mathrm{tr}}\sum_t\mathcal{E}_{\mathrm{tr},t}(a_t)+\lambda_{\mathrm{roll}}\sum_t\mathcal{L}^{(H)}_{\mathrm{roll},t}\\ &+\lambda_{\mathrm{beh}}\textstyle\sum_t\mathcal{E}_{\mathrm{beh},t}(a_t)+\lambda_{\mathrm{world}}\sum_t\mathcal{E}_{\mathrm{world},t}(a_t),\end{aligned}\]

with all \(\lambda\ge 0\). Observation and rollout terms are summed where their targets exist; energy terms are summed over valid transitions. Positive local curvature of the combined action energy gives a locally unique, perturbation-stable MAP action (Theorem 1).

3.6Global Temporal MAP

Mobility evidence is coupled across time, so the local factors are composed over the complete query interval:

\[\mathcal{J}_{\mathrm{MAP}}:=\beta_{\mathrm{obs}}\mathcal{L}_{\mathrm{obs}}+\beta_{\mathrm{dyn}}\mathcal{L}_{\mathrm{dyn}}+\beta_{\mathrm{act}}\mathcal{L}_{\mathrm{act}}+\beta_{\mathrm{world}}\mathcal{L}_{\mathrm{world}}.\]

\(\mathcal{L}_{\mathrm{obs}}\) anchors exposed states to positioning evidence, \(\mathcal{L}_{\mathrm{dyn}}\) couples adjacent states through the action-conditioned transition, \(\mathcal{L}_{\mathrm{act}}\) measures plausibility under the profile-conditioned actor, and \(\mathcal{L}_{\mathrm{world}}\) measures geospatial support. These factors define an unnormalized path density \(p(\mathbf{z}_q\mid\mathcal{E}_q)\propto\mathbf{1}[\mathbf{z}_q\in\Omega^{\mathrm{MAP}}_q]\exp\{-\mathcal{J}_{\mathrm{MAP}}(\mathbf{z}_q)\}\), and the reconciled path is its mode:

\[\widehat{\mathbf{z}}_q=(\widehat{\mathbf{s}}_q,\widehat{\mathbf{a}}_q):=\arg\min_{\mathbf{z}_q\in\Omega^{\mathrm{MAP}}_q}\mathcal{J}_{\mathrm{MAP}}(\mathbf{z}_q).\]

Both states and actions are optimized. An exposed state may move away from its noisy encoder initialization to agree with neighboring transitions; a missing state is reconstructed from evidence on both temporal sides; each action is adjusted to explain the inferred state change while staying behaviorally plausible and geospatially supported. Hidden states are initialized only from visible boundary information, and their true coordinates are never encoded. At evaluation the solver takes 8 updates (GeoLife) from initial step 0.25, normalizes the joint state–action gradient, restores anchors, halves the step up to 12 times until the objective decreases, and returns the best accepted iterate.

3.7Bilevel training and implemented objective

With \(\Theta\) fixed, the inner solver takes \(K_{\mathrm{MAP}}\) projected-gradient steps on all states and actions; training differentiates through it:

\[\widehat{\mathbf{z}}^{(K_{\mathrm{MAP}})}_{\Theta,q}=\mathrm{Solve}^{K_{\mathrm{MAP}}}_\Theta\big(\mathbf{z}^{(0)}_q\big),\]
\[\Theta^\star=\arg\min_\Theta\ \mathbb{E}_{q\sim\mathcal{D}_{\mathrm{train}}}\,\mathcal{L}_{\mathrm{SCL}}\big(\Theta;\widehat{\mathbf{z}}^{(K_{\mathrm{MAP}})}_{\Theta,q},\mathcal{E}_q\big).\]

The supplementary material specifies the implemented final-stage objective. Let \(\bar{s}_{t+1}=\mathrm{sg}[\mu_{\bar\phi}(o_{t+1})]\) be the EMA target, \(\hat{s}_{t+1}=\mathbb{E}[p_\theta(\cdot\mid s_t,a_t)]\), and \(\langle\cdot\rangle_m\) a mean over mask \(m\) (\(m^{\mathrm{pair}}\): active transitions, \(m^{\mathrm{obs}}\): observed states). The state terms are

\[\mathcal{J}_{\mathrm{pred}}=\Big\langle\lVert\mathrm{LN}(\hat{s}_{t+1})-\mathrm{LN}(\bar{s}_{t+1})\rVert_2^2\Big\rangle_{m^{\mathrm{pair}}}+\Big\langle\frac{\lVert\ell_\chi(\hat{s}_{t+1})-x_{t+1}\rVert_2^2}{2(25\,\mathrm{m})^2}\Big\rangle_{m^{\mathrm{pair}}}+\mathcal{R}_{\mathrm{var}},\]
\[\mathcal{J}_{\mathrm{emit}}=\Big\langle\rho_{1000}\Big(\frac{\lVert\ell_\chi(s_t)-x_t\rVert_2^2}{2(10\,\mathrm{m})^2}\Big)\Big\rangle_{m^{\mathrm{obs}}},\qquad \rho_\nu(u)=\nu\log\big(1+\max(u,0)/\nu\big),\]

where LN is layer normalization and \(\mathcal{R}_{\mathrm{var}}\) prevents representation collapse. Actions are first discovered from the transition alone, starting at zero, and the actor is then fit to the transition-supported solution \(a^\dagger_t\), so an untrained actor never defines the variable it later models:

\[a^{(r+1)}_t=a^{(r)}_t-0.05\,\nabla_{a_t}\big[-\log p_\theta\big(\bar{s}_{t+1}\mid s_t,a^{(r)}_t\big)\big],\qquad r=0,\dots,7,\]
\[\mathcal{J}_{\mathrm{act}}=\Big\langle-\log p_\theta\big(\bar{s}_{t+1}\mid s_t,a^\dagger_t\big)-\lambda_\pi\log\pi_\psi\big(a^\dagger_t\mid\xi_t\big)\Big\rangle,\]

with implemented actor context \(\xi_t=(s_t,a_{t-1},\alpha,g_t,c_q)\). Executable grounding scores the legal outgoing edges \(e\in\mathcal{A}_W(v_t)\), each defining a legal action \(\zeta_W(e)\) with endpoint mismatch \(D_t(e)\):

\[\mathcal{J}_{\mathrm{exec}}=-\log\sum_{e\in\mathcal{A}_W(v_t)}\exp\Big[-D_t(e)-\widetilde{E}^{\pi}_t(e)-0.25\,\widetilde{E}^{p}_t(e)-0.05\,\widetilde{E}^{W}_t(e)-0.05\,\widetilde{V}_t(e)\Big].\]

The full final-stage objective is

\[\begin{aligned}\mathcal{J}=\ &\mathcal{J}_{\mathrm{pred}}+\mathcal{J}_{\mathrm{emit}}+\mathcal{J}_{\mathrm{act}}+0.2\,\mathcal{J}_{\mathrm{roll}}+\mathcal{J}_{\mathrm{metric}}+\mathcal{J}_{\mathrm{actor\text{-}metric}}+0.5\,\mathcal{J}_{\mathrm{component\text{-}metric}}\\ &+0.1\,\mathcal{R}_\pi+0.2\,\mathcal{J}_{\mathrm{exec}}+0.1\,\mathcal{J}_{\mathrm{world\text{-}cal}}+0.5\,\mathcal{J}_V+0.2\,\mathcal{J}_D+0.1\,\mathcal{E}_{\mathrm{MAP}},\end{aligned}\]

with the spatial MAP term weighted by \(\lambda_W=0.01\). \(\mathcal{J}_{\mathrm{roll}}\) applies the actor and transition expectations recursively for \(H=5\) steps and averages transition NLL and a 25 m-scaled metric error over all cases and over moving cases. \(\mathcal{J}_{\mathrm{metric}}\) and its actor and per-component variants train a diagnostic decoder of normalized displacement, stay probability \(p^{\mathrm{stay}}_t=\exp[-(\lVert\Delta y_t\rVert/25)^2]\), and speed. \(\mathcal{J}_{\mathrm{world\text{-}cal}}\) calibrates \(\kappa_\omega\) with Smooth-L1 to the target \(\bar{E}^W_t=p^{\mathrm{move}}_t(d^{\mathrm{road}}_t/20)^2+p^{\mathrm{stay}}_t(d^{\mathrm{poi}}_t/50)^2\). \(\mathcal{J}_V\) and \(\mathcal{J}_D\) fit a query-value head and a six-component destination prior. No term uses downstream labels.

4Theoretical analysis (RQ1, RQ3)

The analysis separates model identifiability, recovering a latent parameterization from the observation law, from conditional path identifiability, the local uniqueness of a MAP state–action solution once the learned interfaces are fixed.

Proposition 1 (non-identifiability under action reparameterization)

Let \(h:\mathcal{A}\to\mathcal{A}\) be a \(C^1\) bijection, \(a'_t=h(a_t)\), and define

\[p^h_\theta(s_{t+1}\mid s_t,a'_t)=p_\theta\big(s_{t+1}\mid s_t,h^{-1}(a'_t)\big),\qquad \pi^h_\psi(a'_t\mid h^h_t)=\pi_\psi\big(h^{-1}(a'_t)\mid h_t\big)\,\big|\det J_{h^{-1}}(a'_t)\big|.\]

Composing every action-dependent interface with \(h^{-1}\) leaves the distribution of positioning trajectories unchanged. Passive trajectories alone therefore cannot identify action coordinates or unique semantic action names.

MobilityWorld fixes an operational coordinate convention (the dense metric action projection, metric diagnostic targets, and deterministic edge-to-action encoding) and makes conditional claims within it. Fix \(\Theta\), the neighboring states, and the query context, and write the action-dependent local MAP energy as \(j_t(a)=\beta_{\mathrm{dyn}}\mathcal{E}_{\mathrm{tr},t}(a)+R_t(a)\), where \(R_t\) collects the behavioral, world, boundary, and neighboring-action terms.

Theorem 1 (local conditional identifiability and stability of a free action)

Assumption 1. On a convex neighborhood \(\mathcal{N}_t\) of a stationary action \(a^\star_t\), \(\mathcal{E}_{\mathrm{tr},t}\) and \(R_t\) are \(C^2\) and

\[\nabla^2_a\mathcal{E}_{\mathrm{tr},t}(a)\succeq\mu_d I,\qquad \nabla^2_a R_t(a)\succeq-\beta I,\qquad \beta_{\mathrm{dyn}}\mu_d>\beta.\]

Then \(j_t\) is \(\mu_a\)-strongly convex on \(\mathcal{N}_t\) and \(a^\star_t\) is its unique local MAP action. If a perturbed objective \(\tilde{j}_t\) has a stationary point \(\tilde{a}_t\in\mathcal{N}_t\) and \(\sup_{a\in\mathcal{N}_t}\lVert\nabla\tilde{j}_t(a)-\nabla j_t(a)\rVert_2\le\varepsilon\), then

\[\mu_a=\beta_{\mathrm{dyn}}\mu_d-\beta>0,\qquad \lVert\tilde{a}_t-a^\star_t\rVert_2\le\varepsilon/\mu_a.\]

The actor and world terms need not be convex; their most negative curvature only has to be dominated by transition information. In the linear–Gaussian case (Corollary 1, with next-state belief \(\mathcal{N}(\mu_o,R)\), transition \(\mathcal{N}(f+Ba,Q)\), and actor \(\mathcal{N}(\mu_\pi,P)\)) the MAP action is the precision-weighted fusion of the data-implied action \(a_d=\Lambda_d^{-1}\eta_d\) and the behavior-implied action \(\mu_\pi\):

\[a^\star=(\Lambda_d+\Lambda_\pi)^{-1}(\Lambda_d a_d+\Lambda_\pi\mu_\pi),\qquad \Lambda_d=B^\top(R+Q)^{-1}B,\]

with \(\eta_d=B^\top(R+Q)^{-1}(\mu_o-f)\), \(\Lambda_\pi=P^{-1}\), and \(\Lambda_d\succ 0\). If \(\Lambda_d\) is singular, the positive actor precision still resolves the transition-null directions.

Theorem 2 (structural information completes local identification)

Let \(H_0\succeq 0\) be the local Hessian of the observation–transition–actor objective and \(H_W\succeq 0\) the curvature added by the world and executable-action grounding. If \(\mathrm{null}(H_0)\cap\mathrm{null}(H_W)=\{0\}\), then \(H_0+H_W\succ 0\); if additionally \(H_0\succ 0\),

\[(H_0+H_W)^{-1}\preceq H_0^{-1},\]

so the local posterior variance in every direction, and its trace, cannot increase when structural evidence is added.

Theorem 3 (global temporal evidence propagation)

Linearize the observation, dynamics, actor, and world residuals around a stationary path \(\mathbf{z}=(s_{1:T},a_{1:T-1})\), giving \(J_{\mathrm{quad}}(\mathbf{z})=\tfrac12\sum_r\lVert M_r\mathbf{z}-b_r\rVert^2_{W_r}\) and \(H=\sum_r M_r^\top W_r M_r\). If \(H\succ 0\), then

\[\mathbf{z}^\star=H^{-1}\sum_r M_r^\top W_r b_r,\qquad \delta\mathbf{z}^\star=H^{-1}M_{o,j}^\top W_{o,j}\,\delta b_{o,j}.\]

Without cross-time factors \(H\) is block diagonal and a perturbation at time \(j\) stays local; transition and previous-action factors add off-diagonal blocks, so \(H^{-1}\) propagates evidence into unobserved intervals.

Theorem 4 (legality and finite-horizon score regret)

Every route returned by Plan is directed-edge legal in \(W_q\). Let \(J(r)=\sum_k c_k(r)\) be an ideal and \(\widehat{J}(r)=\sum_k\hat{c}_k(r)\) the learned cumulative route energy over routes \(\mathcal{R}^H_q\) of at most \(H\) continuations. If \(|\hat{c}_k-c_k|\le\varepsilon\) on every feasible prefix and search returns \(\hat{r}\) with \(\widehat{J}(\hat{r})\le\min_{r\in\mathcal{R}^H_q}\widehat{J}(r)+\xi\), then for \(r^\star=\arg\min_{r\in\mathcal{R}^H_q}J(r)\)

\[J(\hat{r})-J(r^\star)\le 2H\varepsilon+\xi.\]

Legality is exact because it follows from enumerating only legal continuations. The regret bound is conditional on scoring error \(\varepsilon\) and search error \(\xi\); it does not guarantee that bounded search finds a route. Theorems 1–3 are local, second-order statements; mixture transitions and alternative legal routes can still produce several global solutions.

5Experimental protocol

GeoLife (Beijing) has 19,878,589 GPS records from 177 users (10,314 agent-days, irregular cadence with median 2 s); the Atlanta Trajectory Simulation has 43,201,994 records from 1,000 agents (31,000 agent-days, fixed 60 s cadence). Both use OpenStreetMap roads and POIs (GeoLife: 295,755 directed edges, 102,134 POIs; Atlanta: 133,021 edges, 46,525 POIs). Splits are trajectory-disjoint and keep anonymized identities for re-identification. One checkpoint is trained per dataset; every task uses it without fine-tuning or learned heads, and only the query evidence, operator, and readout change.

6.3Executable and counterfactual planning (RQ3)

A multi-constraint query requires the route to enter a visit region, stay within a length budget, reach the destination within 50 m, and use only legal directed edges. Over the 64 queries, MobilityWorld routes have mean DTW 39.24 m, Overlap@50 m 0.614, and a length ratio of 0.997 to the constrained shortest path. Table 9 lists the four displayed queries.
