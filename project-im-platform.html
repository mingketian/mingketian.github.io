OVERVIEW

A hybrid distributed instant messaging platform: Java Spring Cloud microservices behind a horizontally scalable Netty WebSocket cluster, with ordered, lossless asynchronous delivery and zero-downtime releases.

How it works

  1. 01

    Hybrid architecture

    Java Spring Cloud microservices work alongside a Netty-based WebSocket cluster, with every tier designed to scale horizontally.

  2. 02

    Discovery and routing

    ZooKeeper-based service discovery tracks the stateful Netty nodes, and RabbitMQ fan-out routing is tuned for low intra-cluster latency.

  3. 03

    Asynchronous pipelines

    High-throughput asynchronous messaging handles burst traffic with ordered delivery and no message loss; Redis holds distributed sessions and drives failover recovery.

  4. 04

    Deployment and storage

    Containerized services roll out with rolling upgrades and horizontal scaling for zero-downtime releases; MinIO object storage and relational databases support multimedia and social features.

Results

  • 80k–120kconcurrent connections
  • 15k–25kmessages per second in bursts, delivered in order with no loss
  • 40–70 msp95 intra-cluster latency under high concurrency
  • Zerodowntime during releases
